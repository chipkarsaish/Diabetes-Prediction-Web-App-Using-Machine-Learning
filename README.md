# Diabetes-Prediction-Web-App-Using-Machine-Learning

A simple machine learning-based web application built with Streamlit that predicts whether a person is diabetic or non-diabetic based on their glucose and blood pressure levels. The model was trained using a Jupyter Notebook (Diabetis_detection_system.ipynb) and then deployed using a Streamlit interface for user interaction. This project demonstrates how to integrate machine learning models into user-friendly web apps.
